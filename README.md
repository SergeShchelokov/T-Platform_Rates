# Т.Платформа — Тарифы

Интерактивный прототип раздела по [макетам Figma](https://www.figma.com/design/mFzim43dKPdjzgGAExEK9k/T-Platform?node-id=11474-54771).

[Открыть на GitHub Pages](https://SergeShchelokov.github.io/T-Platform_Rates/)

Предзаполнены три демонстрационных тарифа: «ФЛАЙТ + контроль топлива», «АвтоГРАФ.WEB — мониторинг» и будущий «Агросервисы — сезонный контроль». У каждого по три версии. Доступны таблица (по умолчанию) и карточки, поиск, создание тарифа с первой версией, изменение названия и комментария, создание и редактирование версий, список услуг и подтверждение удаления версии. При пустом списке предусмотрен empty state.

## Данные и правила

- Данные сохраняются в localStorage данного браузера. Демонстрационные тарифы добавляются один раз при обновлении; существующие пользовательские тарифы сохраняются. Даты примеров определяются относительно дня первой загрузки новой версии.
- Цены хранятся целым числом копеек. При наличии услуг итог равен сумме строк. В рамках формы ручная цена сохраняется при добавлении и удалении услуг.
- Расчётная единица — сутки, поле периода всегда недоступно для изменения. Сегодня определяется в часовом поясе Asia/Yekaterinburg. Дата начала версии выбирается вручную, допускаются сегодня и будущие даты. Прошлые даты недоступны в календаре и отклоняются при ручном вводе. Повторная дата внутри одного тарифа отклоняется.
- Действующая версия определяется по последней наступившей дате. Будущая версия заранее не изменяет действующую цену. Редактирование и удаление запрещены, если дата прошла или у версии отмечен выполненный расчёт.
- Версия с сегодняшней датой сразу становится действующей (зелёный бейдж), с будущей — запланированной (фиолетовый). В параметрах показывается действующая версия, а при её отсутствии — ближайшая запланированная. Будущая цена не включается в текущие начисления.
- Тариф создаётся вместе с обязательной первой версией. Единственную оставшуюся версию удалить нельзя: блокировка действует в истории, в футере и при подтверждении удаления. Сначала нужно создать другую версию. Ранее сохранённые пустые тарифы автоматически удаляются при загрузке; тарифы с версиями сохраняются.
- Название и комментарий относятся ко всему тарифу, а не к отдельным версиям. Их редактирование перенесено в общую форму «Новая версия тарифа»: сохранение обновляет эти поля и сохраняет версию условий. Пустой комментарий в просмотре не отображается.
- Статусы, сводки и цены в обоих представлениях определяются из одного набора данных. Сумма за сутки равна действующей цене за объект, умноженной на общее количество объектов подключённых организаций.
- Тариф «ФЛАЙТ + контроль топлива» демонстрирует назначения: «АгроВектор» — 12 объектов, «ТрансЛогистика» — 8, «УралАгро» — 5. При цене 30 ₽ за объект получается 750 ₽ в сутки. У «АвтоГРАФ.WEB» — 40 объектов × 12 ₽ = 480 ₽ в сутки. У будущего тарифа — 18 объектов и 0 ₽ начислений до начала действия. Новые пользовательские тарифы создаются без назначений. В карточке данные организаций помечены как демонстрационные; реальные организации не подключаются.
- После создания карточка закрывается и появляется зелёный баннер об успешном создании. В футерах сайдпейджей используется кнопка «Закрыть». При наведении карточки немного приподнимаются и усиливают тень; учитывается настройка уменьшения анимации.

Прототип работает на стороне браузера. Серверный биллинг, реальные расчёты, авторизация и другие разделы навигации требуют подключения API платформы.

## Разработка

Vue 3, TypeScript, Vite, Vuetify 0 Headless. Tabs, Dialog, Button, Popover и Calendar обеспечивают взаимодействия и доступность. Шрифт и оригинальные ассеты Figma поставляются локально.

```sh
npm ci
npm run dev
npm test
npm run build
```

Публикация через GitHub Actions при push в main. Для проекта задан base path `/T-Platform_Rates/`. Папка dist собирается в CI.
