# Т.Платформа — Тарифы

Интерактивный прототип раздела по [макетам Figma](https://www.figma.com/design/mFzim43dKPdjzgGAExEK9k/T-Platform?node-id=11474-54771).

[Открыть на GitHub Pages](https://SergeShchelokov.github.io/T-Platform_Rates/)

Первый запуск открывает пустой список. Кнопка «Создать» запускает создание тарифа с первой версией. Затем доступны таблица и карточки, поиск, изменение названия и комментария, создание и редактирование версий, список услуг и подтверждение удаления версии.

## Данные и правила

- Данные создаются пользователем и сохраняются в localStorage данного браузера. Для нового прохождения с пустого списка можно открыть сайт в приватном окне.
- Цены хранятся целым числом копеек. При наличии услуг итог равен сумме строк. В рамках формы ручная цена сохраняется при добавлении и удалении услуг.
- Расчётная единица — сутки. Сегодня определяется в часовом поясе Asia/Yekaterinburg. Дата начала версии выбирается вручную, допускаются сегодня и будущие даты. Повторная дата внутри одного тарифа отклоняется.
- Действующая версия определяется по последней наступившей дате. Будущая версия заранее не изменяет действующую цену. Редактирование и удаление запрещены, если дата прошла или у версии отмечен выполненный расчёт.
- Удаление последней версии оставляет карточку тарифа с состоянием «Нет действующей версии» и возможностью добавить новую.
- Название и комментарий относятся ко всему тарифу. Их изменение не создаёт новую версию.
- Статусы, сводки и цены в обоих представлениях определяются из одного набора данных. Организации и объекты в этом прототипе не назначаются тарифам, поэтому их количество и доход от назначений равны нулю.

Прототип работает на стороне браузера. Серверный биллинг, реальные расчёты, авторизация и другие разделы навигации требуют подключения API платформы.

## Разработка

Vue 3, TypeScript, Vite, Vuetify 0 Headless. Tabs, Dialog, Button, Popover и Calendar обеспечивают взаимодействия и доступность. Шрифт и оригинальные ассеты Figma поставляются локально.

```sh
npm ci
npm run dev
npm test
npm run build
```

Публикация через GitHub Actions при push в main. Для проекта задан base path `/T-Platform_Rates/`. Папка dist собирается в CI.
